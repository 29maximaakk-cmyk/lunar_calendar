# Лунный календарь (садовода)

Многоязычная утилита для определения фаз Луны, лунного дня, знака зодиака Луны и получения рекомендаций для садовода на указанную дату.  
Помогает планировать посадки, полив, обрезку и другие работы в саду и огороде в соответствии с биоритмами растений.

## Особенности
- Расчёт возраста Луны (лунный день) от 1 до 30.
- Определение фазы Луны: новолуние, первая четверть, полнолуние, последняя четверть.
- Вычисление знака зодиака, в котором находится Луна.
- Рекомендации для садовода: благоприятные/неблагоприятные дни для посадки, полива, обрезки, сбора урожая, борьбы с вредителями.
- Возможность указать произвольную дату (по умолчанию сегодня).
- Вывод в консоль с цветовой индикацией (где поддерживается).
- Экспорт результатов в JSON и CSV.
- Поддержка аргументов командной строки для автоматизации и интеграции со скриптами.

## Установка и запуск
Для каждого языка требуются соответствующие инструменты и зависимости.

### Запуск на разных языках

1. **Python**  
   Установка: `pip install colorama` (опционально).  
   Запуск: `python lunar_calendar.py --date 2026-08-26 --json result.json`

2. **JavaScript (Node.js)**  
   Установка: `npm install commander chalk`  
   Запуск: `node lunar_calendar.js --date 2026-08-26`

3. **Go**  
   Установка: модулей не требуется.  
   Запуск: `go run lunar_calendar.go --date 2026-08-26`

4. **Rust**  
   Добавьте `clap` и `chrono` в `Cargo.toml`.  
   Запуск: `cargo run -- --date 2026-08-26`

5. **Java**  
   Используйте стандартную библиотеку и Gson.  
   Сборка: `javac -cp gson.jar LunarCalendar.java`  
   Запуск: `java -cp .;gson.jar LunarCalendar --date 2026-08-26`

6. **C# (.NET Core)**  
   Установка: `dotnet add package Newtonsoft.Json`  
   Запуск: `dotnet run -- --date 2026-08-26`

7. **C++ (Linux)**  
   Требуется компилятор с C++11 и библиотека `nlohmann/json`.  
   Сборка: `g++ -std=c++11 -o lunar_calendar lunar_calendar.cpp -ljsoncpp`  
   Запуск: `./lunar_calendar --date 2026-08-26`

8. **Kotlin (JVM)**  
   Используйте Gson.  
   Сборка: `kotlinc -cp gson.jar LunarCalendar.kt`  
   Запуск: `kotlin -cp .;gson.jar LunarCalendarKt --date 2026-08-26`

## Использование

Общие аргументы командной строки (везде, где поддерживается):

- `--date <YYYY-MM-DD>` – дата для расчёта (по умолчанию сегодня).
- `--json <файл>` – экспортировать результат в JSON.
- `--csv <файл>` – экспортировать результат в CSV.
- `--verbose` – подробный вывод (включая все рекомендации).
- `--no-color` – отключить цветной вывод.

python lunar_calendar.py --date 2024-12-25 --json report.json --verbose
